# תערוכת AI — כיתה ז׳4 | בית ספר עלי

אתר סטטי המציג 16 פרויקטים של תלמידי הכיתה.

## פרסום

1. חלצו את כל קובצי ה-ZIP.
2. העלו את התכולה (כולל `index.html`, התיקיות `projects` ו-`assets`) לשורש מאגר GitHub.
3. ב-Vercel בחרו Import Git Repository, ובחרו Framework Preset: **Other**, Root Directory: `./` וללא Build Command.
4. Deploy.

הפרויקטים הם קובצי HTML מקוריים של התלמידים, בתיקייה `projects/`. חלקם דורשים חיבור לאינטרנט כדי לטעון ספריות חיצוניות. ניתן לעדכן כותרות ותיאורים בקובץ `script.js`.
